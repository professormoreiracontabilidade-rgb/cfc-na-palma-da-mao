CFC NA PALMA DA MÃO — CORREÇÃO V4.1

Este pacote contém três arquivos:
- firebase-config.js
- login.js
- login.html

COMO INSTALAR
1. Abra a pasta local do repositório cfc-na-palma-da-mao.
2. Substitua os três arquivos existentes pelos arquivos deste pacote.
3. No GitHub Desktop, faça um commit com o resumo:
   Correção do login Firebase V4.1
4. Clique em Push origin.
5. Aguarde o GitHub Pages atualizar.
6. Teste em janela anônima.

IMPORTANTE
- Esta versão usa somente o Firebase SDK modular.
- Não usa o objeto global "firebase".
- Isso elimina os erros "firebase is not defined" e "app/no-options".

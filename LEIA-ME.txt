CFC NA PALMA DA MÃO — RESTAURAÇÃO SEM FIREBASE

Este pacote remove a exigência de login e devolve o acesso direto ao aplicativo.

Substitua no repositório:
- auth-guard.js
- logout.js
- firebase-config.js
- login.js
- login.html

Depois:
1. Abra o GitHub Desktop.
2. Faça o commit com a mensagem:
   Remover Firebase e restaurar acesso direto
3. Clique em Push origin.
4. Aguarde a publicação do GitHub Pages.
5. Teste em janela anônima.

RESULTADO:
- index.html abre diretamente;
- nenhuma sessão é exigida;
- login.html encaminha para index.html;
- referências antigas aos arquivos não causam erro 404.

Este pacote não altera quizzes, imagens, links ou demais páginas.
